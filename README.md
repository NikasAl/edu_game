# Edu Game — учебник как игра

Прототип обучающей системы, которая перекладывает произвольные учебные материалы
(учебники, статьи, конспекты) в игровой процесс: карта знаний, атомы идей,
испытания, видимый прогресс и «продолжить с места остановки» — как в игре.

Идея: игра живёт не в украшательствах (очки, бейджи, анимации), а в **структуре
прогрессии** — доступ к новому открывается через освоение старого, как в
metroidvania. Подробный дизайн-концепт см. в обсуждении проекта.

## Как это работает

### Ядро: атом идеи

Единица системы — не параграф, а **атом идеи**, удовлетворяющий трём критериям:

1. формулируется одним предложением;
2. иллюстрируется одним примером;
3. проверяется хотя бы одним автопроверяемым вопросом.

Атомы соединяются рёбрами двух типов:

- **hard** — без этой идеи понять нельзя (жёсткий гейт);
- **soft** — помогает, но не обязательна (узел доступен, но помечен «рискованно»).

### Игровой цикл

```
КАРТА (куда идти; рекомендация «золотого пути» всегда видна)
 → КАРТОЧКА ИДЕИ (одна формулировка + один пример + частая ошибка)
   → Испытание 1: ФЕЙНМАН — объясни своими словами (LLM-рубрика)
   → Испытание 2: ЗАДАЧИ — параметрические шаблоны, автопроверка без LLM
   → Испытание 3: СВОЯ ЗАДАЧА — придумай и проверь (LLM-валидация)
 → узел «освоен», карта перерисовывается, открываются новые узлы
 → автосейв после каждого шага; «Продолжить» возвращает точно на место
```

Гибридная прогрессия: золотой путь (топологический порядок hard-зависимостей)
жёсткий, боковые ветви можно проходить в любом порядке; вход в узел с
непокрытыми soft-зависимостями разрешён с предупреждением «рискованно».

### Дозированность

Один экран = одна идея. Всё остальное (зависимости, контекст) живёт на карте.
Анимации не входят в основной контур — только как опция-иллюстрация (в планах).

## Демо-курс

При первом запуске загружается курс **«Алгебра и начала анализа: Производная»**:
12 атомов в 3 регионах, гибридный граф зависимостей, 24 параметрические задачи
с машинно-проверяемыми ответами (решатели считаются безопасным интерпретатором
выражений, без `eval`). Весь цикл проходится без LLM: для фейнмановских
объяснений работает локальный демо-оценщик (эвристики), для «своих задач» —
честная самопроверка.

## LLM-операции

Подключается любой OpenAI-совместимый провайдер (Настройки → Добавить):
OpenAI, OpenRouter, DashScope/Qwen, локальные Ollama / llama.cpp / vLLM / LM Studio.

| Операция | Когда | Кэш |
|---|---|---|
| Разбор текста на атомы + граф зависимостей | ингест (редко) | в БД |
| Генерация параметрических задач + решателей | ингест (редко) | в БД |
| Проверка фейнмановского объяснения по рубрике | в игре | — |
| Проверка «своей задачи» (на тему? решаема?) | в игре | — |
| Подсказки уровня 1–3 | по запросу | — |

Самоверификация задач: LLM генерирует шаблон с решателем, значения параметров
рандомизируются при каждой попытке (защита от «запомнил ответ» и основа будущих
интервальных повторений).

## Архитектура

- **Next.js 16 + TypeScript**, один маршрут `/`, всё приложение — клиентское
  (локально-first, работает офлайн после загрузки).
- **Dexie (IndexedDB)** — локальная БД: материалы, регионы, узлы, рёбра, задачи,
  попытки, прогресс, провайдеры. Живые запросы (dexie-react-hooks) — прогресс
  на карте обновляется мгновенно.
- **Zustand** — UI-состояние (вкладки, тема, ингест-черновик).
- **@xyflow/react** — карта знаний: вертикальные слои по глубине
  hard-зависимостей, статусы узлов, жёсткие/мягкие рёбра.
- **Capacitor** — сборка APK; `NativeHttp`-плагин (паттерн NutriAdvisor) обходит
  CORS Android WebView для прямых вызовов LLM.
- Статус узла **вычисляется**, а не хранится: последняя попытка по каждому
  испытанию + гейты по рёбрам. Автосейв — запись попытки в IndexedDB.

```bash
npm install

```

```bash
npm run build                # статическая сборка в out/
npx cap add android          # один раз
npx cap sync android
npx cap open android         # Android Studio → Run / assembleRelease
```

## Импорт своих материалов

Вкладка «Импорт»: название + текст главы/статьи (от ~500 знаков) → LLM выделяет
атомы, строит регионы и граф зависимостей (циклы в hard-рёбрах автоматически
понижаются до soft) → ревью с правкой названий/формулировок → сохранение и
генерация задач по каждому атому. Материал становится активной картой.

Экспорт/импорт всего (материалы + прогресс + провайдеры) — один JSON-файл
в настройках.

src/lib/llm-client.ts   OpenAI-совместимый клиент (браузер + native HTTP)
